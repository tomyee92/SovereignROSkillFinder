    Unofficial fan tool. Pokémon data and pictures come from the Sovereign RO Pokédex; pictures are loaded straight from their site. The ★ Rare category is hidden in the game and not shown by its website, so that list is collected by players as they find them and is incomplete. Data is a snapshot (see date at the top) and can go out of date when the server changes — run scripts/update_data.py to refresh.

    Skill tags (AOE / Single / Support) are approximate. Whether a skill hits an area comes from the rAthena Renewal skill database; how hard it hits depends on this server and the Pokémon's own stats, which this page does not show.
